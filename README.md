# Business Performance Dashboard

## Project Overview

This project presents and interactive business performance dashboard developed using Microsoft Power BI. The dashboard provides a clear view of key business metrics, trends and performance indicators to support data-driven decision making.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Features

- Interactive KPI cards
- Sales and profit analysis
- Performance trend analysis
- Category and segment analysis
- Interactive slicers and filters
- DAX-based calculations
- Business insights and visual reporting

## Key Skills Demonstrated

- Data Cleaning and transformation
- Data modeling
- DAX calculations
- Interactive dashboard development
- Data visualization
- Business performance analysis

## Project File

The complete Power BI dashboard is available in: `PowerBI-Report.pbix`

## Key Insights

The dashboard helps identify business performance trends, compare different categories and segments, and analyze sales and profitability to support business decisions.
